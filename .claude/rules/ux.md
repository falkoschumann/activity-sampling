# UI/UX Guidelines (based on ISO 9241-110 / CPUX-F)

For every change to user interfaces:

- Error messages say what went wrong and how the user can fix it. No technical
  codes alone.
- Every action provides visible feedback (loading state, success, error).
- Destructive actions are reversible or require confirmation.
- Form fields have visible labels, required fields are marked, and input is
  preserved when errors occur.
- Everything is operable by keyboard; focus is visible.
- Identical things are named and behave identically everywhere (terms, button
  placement).
- When unsure about user requirements: ask instead of guessing.
