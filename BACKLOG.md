# Backlog

Open and completed tasks. The order reflects priority: higher up means more
important.

Each entry begins with a category:

```markdown
- [ ] **Category** Description
```

**Categories:** domain topics such as `Activity`, `Calendar`, `Timer`,
`Timesheet`, `Report`, `Estimate`, `Statistics`, `Burn-up`, or qualities such as
`Functionality`, `Usability`, `Reliability`, `Performance`, `Supportability`,
`Security` (FURPS+).
